RUN IN VS CODE:
1. Extract this ZIP.
2. Open VS Code > File > Open Folder > choose MehvishBlogProject_v2.
3. Install the Live Server extension by Ritwick Dey.
4. Open index.html and click Go Live at the bottom of VS Code.
5. If Go Live does not appear, use Terminal > New Terminal and run:
   python3 -m http.server 8000
   Then visit http://localhost:8000

PERSONALISE:
- Add your own photos into the assets folder.
- Edit the text in index.html.
- Replace your-email@example.com with your email address.

PUBLISH WITH GITHUB PAGES:
1. Create a GitHub repository named my-personal-blog.
2. In the VS Code terminal run:
   git init
   git add .
   git commit -m "Create my personal blog"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/my-personal-blog.git
   git push -u origin main
3. On GitHub, open Settings > Pages.
4. Select Deploy from a branch, branch main, folder /(root), then Save.
5. Your published link will appear in Settings > Pages.
